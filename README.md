# Passport Editor

Редактор паспорта изделия: холст-«лист» 650×1000 px, слои, текст/линии/изображения,
умное выравнивание и **печать на листе A4**.

Весь код приложения находится в **одном файле — [`src/app.js`](src/app.js)**
(логика, компоненты, стили, печать, экспорт PDF). `index.html` подключает именно его.

## Запуск

```bash
npm install     # поставить node-модули
npm run dev     # дев-сервер (http://localhost:5173)
npm run build   # прод-сборка в dist/
npm run preview # предпросмотр сборки
npm run lint    # eslint
```

## Что умеет

### Отступы и выравнивание, как в Figma
- **Умные направляющие**: при перетаскивании и растягивании элемент прилипает
  к краям и центрам других элементов, а также **к краям и центру листа**
  (порог 6 px). `Ctrl` временно отключает прилипание.
- **Линии отступов**: у выбранного элемента красными линиями с подписями
  показываются расстояния **до краёв листа** (слева / сверху / справа / снизу).
  Значения видны и во время перетаскивания — вместе с бейджем текущих координат.
- **Отступы до соседей**: удерживайте `Alt` — появятся оранжевые линии
  до ближайших элементов с каждой стороны; `Alt` + наведение на конкретный
  элемент покажет расстояние именно до него.
- В панели свойств дублируется схема отступов от края листа в px и в мм.
- Кнопки `📏 Отступы` и `🧲 Прилипание` в тулбаре включают/выключают режимы.

### Блок текста по размеру содержимого (без пустых полей)
- Текстовый блок **сразу создаётся по размеру надписи**: ширина — по самой длинной
  строке, высота — по числу строк. Пустого места вокруг букв больше нет, поэтому
  линии отступов меряют от видимого текста, а не от невидимых краёв старой рамки.
- Блок остаётся **растяжимым вручную**: потяните маркер рамки или впишите Ш/В
  в свойствах — авто-размер по этой оси выключится.
- Вернуть подгонку:
  - **двойной клик по маркеру рамки** на холсте (боковой — ширина, верхний/нижний —
    высота, угловой — и то и другое);
  - кнопка **«⤢ По размеру текста»** в свойствах надписи (рядом — «↔ Ширину», «↕ Высоту»);
  - чекбоксы **«Авто-ширина по тексту»** и **«Авто-высота по тексту»**;
  - **«⤢ По тексту»** в тулбаре — подогнать все надписи сразу (одна запись в истории);
  - в панели свойств группы — «⤢ Подогнать надписи по тексту» для выделенных слоёв.
- При подгонке надпись не «уезжает»: у текста по центру сохраняется центр,
  у текста по правому краю — правый край, верх остаётся на месте.
- Во время ввода текста блок растёт и сжимается **на лету**, как в Figma.
- Многострочный абзац в шаблоне («Транспортировка и хранение…») оставлен с
  фиксированной шириной — она служит границей переноса, — но высота подгоняется.
- Старые JSON-макеты загружаются как раньше: если в файле нет флагов авто-размера,
  геометрия надписей сохраняется без изменений.

### Групповое выделение и порядок слоёв
- **Ctrl/Cmd + клик** по элементу (на холсте или в панели слоёв) — добавить/убрать
  из выделения, **Shift + клик** — добавить, **рамка мышью по фону листа** — выделить
  всё попавшее в прямоугольник (`Ctrl`/`Shift` + рамка — добавить к текущему выделению).
- **Ctrl+A** — выделить всё, **Esc** — снять выделение.
- Группу можно **тянуть мышью целиком** (прилипание считается по общей рамке),
  двигать стрелками, дублировать (`Ctrl+D`) и удалять (`Delete`) — одной записью в истории.
- **Маркеры общей рамки** масштабируют всю группу: размеры и положение слоёв
  пересчитываются пропорционально, шрифт — по среднему коэффициенту.
- В свойствах группы: координаты и размер общей рамки, **выравнивание**
  (по левому/правому краю, центру, верху/низу) и **распределение** с равными
  промежутками по X и Y (нужно 3+ слоя).
- **Порядок слоёв перетаскиванием**: потяните строку в панели слоёв за ручку **⠿**
  и отпустите в нужном месте — синяя линия показывает, куда встанет слой.
  Если строка входит в групповое выделение, переносится вся группа.
  Стрелки ↑/↓ остались для доводки на один шаг.

### Печать на листе A4
- Кнопка **«Печать A4»** (или `Ctrl+P`) открывает диалог с живым предпросмотром листа.
- Формат: **A4**, A3, A5, Letter; ориентация книжная/альбомная; поля листа в мм.
- Масштаб документа: *вписать в лист*, *заполнить лист*, *100 %* или *свой %*.
  Диалог показывает размер листа, область печати, итоговый масштаб и предупреждает,
  если документ выходит за область печати.
- Печатается отдельный «чистовик» без интерфейса: `@page` с точным размером листа
  и нулевыми полями браузера, геометрия пересчитывается в миллиметрах.
  В диалоге печати браузера выбирайте поля «Нет» и масштаб 100 %.
- **«Скачать PDF»** собирает тот же лист в PDF (модули `jspdf` + `html2canvas`,
  рендер ≈288 dpi).

### Поля для ввода текста (бланки)
- Новый тип элемента — **«Поле»** (`+ Поле` в тулбаре): текст с линией снизу — бланк,
  куда вписываются данные паспорта.
- Все места с подчёркиваниями в шаблоне уже заменены такими полями:
  паспорт №, дата, исполнение, наименование, размеры, номер партии, количество,
  пять «СООТВЕТСТВУЕТ», номер ГОСТ.
- Двойной клик (или `Enter` на выделенном поле) — ввод текста, `Enter`/клик мимо — сохранить.
- Значение попадает в печать и PDF; **подсказка (placeholder) видна только на экране**.
- В свойствах: значение, подсказка, шрифт, цвет, выравнивание,
  толщина и цвет линии под полем (можно вовсе отключить).

### Режим наложения слоя (умножение)
- В свойствах любого слоя — «Режим смешивания»: Обычный, **Умножение**, Затемнение,
  Осветление, Перекрытие, Мягкий свет, Затемнение основы, Разница (`mix-blend-mode`).
- Умножение удобно для печатей, штампов и подписей поверх текста — они
  проступают сквозь нижележащий текст, а не перекрывают его белым.
- Режим действует и на холсте, и в печати (`window.print()`), отмечается значком в списке слоёв.
- Особенность: PDF собирается через `html2canvas`, который не поддерживает
  `mix-blend-mode`, — в PDF такие слои печатаются как обычные (диалог печати об этом предупредит).
  Для точного результата с наложением используйте «Печать» → «Сохранить как PDF».

### Толщина линий
- У линии редактируется **толщина**: поле «Толщина линии» в свойствах (от 0.5 px, шаг 0.5),
  быстрые пресеты 0.5 / 1 / 2 / 3 / 5 px, перетаскивание верхнего или нижнего маркера.
- Ранее толщина зажималась общим минимумом 10 px — для линий и полей минимум теперь 0.5 px.

### Прочее
- Слои: видимость, блокировка, порядок (перетаскиванием или ↑/↓), удаление;
  свойства текста (шрифт, размер, цвет, начертание, выравнивание, межстрочный интервал).
- Двойной клик по тексту — редактирование на месте; стрелки — сдвиг на 1 px
  (`Shift` — 10 px); `Ctrl+Z` / `Ctrl+Shift+Z` — отмена и повтор.
- Сохранение и загрузка макета в JSON (`Ctrl+S` — сохранить), вместе с настройками печати.
- Настройки печати и режимы интерфейса запоминаются в `localStorage`.

## Node-модули

| Пакет | Зачем |
| --- | --- |
| `react`, `react-dom` | интерфейс |
| `jspdf` | экспорт листа A4 в PDF |
| `html2canvas` | рендер страницы в растр для PDF |
| `vite`, `@vitejs/plugin-react` | сборка и дев-сервер |
| `eslint` + плагины | проверка кода |

Так как код лежит в файле `.js`, а не `.jsx`, в `vite.config.js` включена поддержка
JSX для `.js` (опции `oxc`, `moduleTypes` и небольшой плагин `jsx-in-js`).
